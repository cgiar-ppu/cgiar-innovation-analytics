## REST API Endpoints (all prefixed with /api)

### Health & Config
- `GET /api/health` — Returns `{"status":"ok","model":"claude-opus-4-6","workspace":"/workspace","auth_method":"api_key","version":"2.0.0"}`
- `GET /api/config` — Full config: model, fallback_model, max_turns, auth_method, version, agent_type, personas (list of 27 agent IDs), memory_categories, platform
- `GET /api/activity` — Activity metrics for cleanup Lambda (connections count, last activity timestamp)

### PRMS Dashboard
- `GET /api/dashboard/prms-stats` — Returns KPIs and chart data from PRMS database:
  - KPIs: total_results (27,803), total_innovations (4,664), innovation_uses (559), active_initiatives (55), countries_covered (183), knowledge_products (12,850)
  - Charts: results_by_type (pie), top_countries (bar), irl_distribution (bar), top_initiatives (bar)
  - Each chart includes: chartType, title, description, xAxisKey, data array, series array with colors
  - Cached in-memory for 5 minutes

## CGIAR-Specific Tools (MCP tools available to agents)

### 1. PRMS Query (`prms_query`)
- Executes read-only SQL against the PRMS SQLite database (197 tables, ~27,800 active results)
- Accepts: SQL query string + natural language question
- Returns: structured result rows with metadata (row count, execution time)
- Safety: validates SQL is read-only (SELECT only), enforces LIMIT 100, 30-second timeout

### 2. Chart Generation (`create_chart`)
- Creates interactive Recharts-compatible chart specifications
- Accepts: chart type, data, axis configuration, title/description
- Returns: full chart config that the frontend renders as Recharts components

### 3. Scenario Analysis (`scenario_analysis`)
- 'What if' portfolio modeling against PRMS baseline data
- 4 scenario types:
  - **reallocation**: Shift capacity between initiatives
  - **irl_advancement**: Model innovation readiness level progression
  - **output_scaling**: Scale initiative output by factor
  - **portfolio_focus**: Model portfolio emphasis shifts
- All outputs clearly labeled [SCENARIO-MODELED] vs [PRMS-VALIDATED]
- Includes sensitivity analysis (optimistic/pessimistic bands)

### 4. Partner Identification (`partner_identification`)
- Finds relevant CGIAR partners for a topic/geography/innovation area
- Combines PRMS partner data (48K+ partner links) with web search
- Returns results labeled [PRMS-VALIDATED] (documented partnerships) or [WEB-SOURCED] (suggestions)
- Covers institution types: CGIAR Centers, Research/University, NGO, Government, Private Sector, etc.

## CGIAR-Specific Agents

### 1. PRMS Data Analyst (`prms_data_analyst`)
- Specialist in querying the PRMS database
- Has the full 197-table schema reference in its system prompt
- Generates and executes SQL, interprets results, creates visualizations

### 2. Innovation Strategy Advisor (`innovation_strategy_advisor`)
- Strategic analysis of innovation portfolios
- Uses scenario analysis for 'what if' modeling
- Provides recommendations based on PRMS data patterns

### 3. Research Synthesizer (`research_synthesizer`)
- Cross-cuts PRMS data to find patterns across initiatives, countries, and innovation types
- Synthesizes findings into narrative summaries

### 4. Report Generator (`report_generator`)
- Creates formatted reports from analysis results
- Supports markdown, charts, and structured output

## CORS Configuration (already in place)
- CORSMiddleware with allow_origins=["*"] (env: CORS_ORIGINS)
- allow_credentials=True
- allow_methods=["*"], allow_headers=["*"]

- WebSocket connections bypass CORS middleware entirely
