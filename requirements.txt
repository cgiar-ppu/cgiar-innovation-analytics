# `import numpy as np`. Without numpy the container fails to boot. The heavier

# and lazy-loaded — prms_search degrades gracefully to "index not available".

# Document generation — required by synapsis/exporters/docx.py (and the
# watermark helper it shares with the AI-content disclaimer banner) for the
# GET /api/export/{id}?format=docx endpoint. Prior to this pin, requirements.txt
# (which Dockerfile.prod installs into the deployed dev/prod container) omitted
# python-docx entirely, so the docx exporter's `from docx import Document`
# raised ImportError -> HTTP 500 in the deployed container even though the
# endpoint worked locally (requirements-macos.txt does list python-docx).
# Version pinned to match the verified local dev environment (see
# requirements-macos.txt). python-pptx / reportlab are NOT imported anywhere
# in synapsis/ so they are intentionally left out of this lean prod list.
python-docx>=1.1.0,<2.0.0

# PDF extraction and verification of generated, watermarked documents.
